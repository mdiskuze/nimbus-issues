# Nimbus releases

Download channel for **Nimbus**, a hyper-local weather app for Lunde, Kramfors and Härnösand in
Västernorrland, Sweden. Radar first, honest about uncertainty, built to answer whether you need a
coat before you open anything.

The source lives in a private repository. This one carries only the signed APKs and their release
notes, so the app can check for a new version without needing a token.

## Install

Grab the newest `.apk` from [Releases](../../releases) and open it.

Android will warn you, because the app is not from the Play Store and Play Protect has never seen
its signing key. In that dialog the small **Install anyway** text is the action, and the prominent
**Got it** button cancels.

Once installed, **Nastaveni → Aktualizace → Zkontrolovat verzi** finds later versions here.
